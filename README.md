# Task 5: Exploratory Data Analysis (EDA) - Amazon Sales Dataset

## 📌 Overview
This repository contains the Exploratory Data Analysis (EDA) completed for **Task 5** of the Data Analyst Internship[cite: 1]. The objective is to extract statistical insights, discover underlying patterns, and visualize feature relationships across cleaned Amazon product sales data using Python (`Pandas`, `Matplotlib`, `Seaborn`)[cite: 1].

---

## 🛠️ Tools & Technologies Used
* **Language:** Python 3.x
* **Libraries:** Pandas, NumPy, Matplotlib, Seaborn
* **Environment:** PyCharm / Jupyter Notebook (`.ipynb`)
* **Deliverables:** Jupyter Notebook, PDF Report, Visualizations, README
